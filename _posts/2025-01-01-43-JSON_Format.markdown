回答を全てJSONで返して欲しい。

ollamaのコマンドに`--format json`をつけると、レスポンスがjsonフォーマットとなる。

```sh
ollama run gemma3n "hi" --format json
```

## 出力の比較

インターネットで言われているように、フォーマットを指定すると、回答の量が少なくなることがわかる。１度しか確認していない。

### フォーマットにJSONを指定した場合

```
~  ollama run gemma3n "hi" --format json
{
  "answer": "Hi there! 👋 How can I help you today?"
}

~  

```

### フォーマットを指定しない場合

```
~  ollama run gemma3n "hi"              
Hi there! 😊 

How can I help you today?  

Do you have a question, need some information, want to 
chat, or something else?  Just let me know!





~  
```

- modelfileにパラメーターとして記載しても、エラーとなる。そのため、引数にフォーマットを取る。
